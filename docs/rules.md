# Rock, paper, scissors: how to play

*The rules as the game plays them now, in plain language. Rock, paper, scissors is the template's example game: replace this file with your own game's rules.*

Two players each pick a hand in secret, then both are revealed at once. Win enough rounds to take the match.

## What's on the table

- A score for each player, starting at 0.
- A target score, chosen when the game is created: 1, 3 (the default) or 5 round wins.

## A round

Both players secretly choose **rock**, **paper** or **scissors**. When both have chosen, the hands are revealed:

- Rock beats scissors, scissors beats paper, and paper beats rock. The winner scores a point.
- The same hand on both sides is a draw, and nobody scores.

## End of the game

As soon as a player's score reaches the target, they win the match.
